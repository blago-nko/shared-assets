# 📱 Руководство по дистрибуции в социальные сети (СУМКа)

> **Протоколы**: SUMKA-2607-001, SAN-2607-001
> **Версия**: 1.0 | **Дата**: 01.08.2026

---

## 1. Назначение

Автоматическое распространение публикаций с 14 сайтов в профильные группы/сообщества.

---

## 2. Этапы внедрения

### Этап 0 (бесплатный)
- 5 постов/сайт/сутки (суммарно до 70/сутки)
- Бесплатные квоты API
- `seo_outreach` в режиме «советник»

### Этап 1 (платный)
- 20 постов/сайт/сутки (суммарно до 280/сутки)
- Платные API-ключи
- `seo_outreach` в автоматическом режиме

---

## 3. Лимиты

### Для чужих групп (`is_owned = false`)
| Параметр | Значение |
|----------|----------|
| Доля с одного сайта | ≤ 33% |
| Суммарная доля | ≤ 50% |
| Окно анализа | 100 постов |
| Кэш | 1 час |

### Для собственных групп (`is_owned = true`)
| Параметр | Значение |
|----------|----------|
| Доля с одного сайта | Не ограничена |
| Суммарная доля | ≤ 80% |

---

## 4. Штрафная пауза

**Триггер**: 3+ неудачных публикаций за 7 дней
**Длительность**: 60 дней
**Действие**: Блокировка публикаций в конкретное сообщество

---

## 5. Видео-Матрица РФ

| Тип контента | Primary (РФ) | Mirror |
|--------------|--------------|--------|
| Аналитика, Блоги, Пантеон | Dzen/Rutube | YouTube |
| Новости, RSS | VK Video | YouTube |
| Карточки САН | VK Video | YouTube |
| Образование | Dzen, Rutube | YouTube |

**Двойное зеркалирование**: Каждое видео → Primary + YouTube.

---

## 6. ИИ-агенты

| Агент | Роль | Этап |
|-------|------|------|
| `content_distributor` | Генерация постов | 0–1 |
| `seo_outreach` | Ссылочная стратегия | 0–1 |
| `publisher` | Мульти-платформенная публикация | 0 |

---
