# 🛠️ Руководство по инструментам разработки

> **Протоколы**: SAM-26-А, SAN-26-А, SUMKA-26-А
> **Версия**: 1.0 | **Дата**: 01.08.2026

---

## 1. Принцип Open Source

Все компоненты экосистемы разрабатываются с использованием Open Source решений.

---

## 2. IDE

### Рекомендуемые
- **VS Code** + плагины:
  - Continue (автодополнение)
  - Cline (агентные задачи)
- **OpenVibe** (российская Open Source AI-IDE)

### Запрещено
- Коммерческие IDE с подпиской (без решения Комитета)
- Платные западные API-ключи

---

## 3. Пакетная обработка

- **Aider** — для массовых изменений
- Собственные скрипты Python/Node.js

---

## 4. LLM

### Предпочтительные
- Локальные модели через **Ollama**:
  - Qwen-Coder
  - CodeLlama

### Допустимые
- **DeepSeek API** (бесплатный пул токенов)
- Российские агрегаторы (оплата в рублях)

### Запрещено
- Платные западные API (OpenAI, Anthropic) без решения Комитета

---

## 5. CI/CD

### GitHub Actions
- Деплой на GitHub Pages (RSS-сайты)
- Деплой на Vercel (САН)
- Еженедельный бэкап метаданных

### Playwright
- E2E-тесты для критических путей

### Линтеры
- ESLint (JS/TS)
- Pylint (Python)
- Проверка покрытия (>80% для критических модулей)

---

## 6. База данных

### Этап 0
- **Supabase Cloud Free** (500 МБ лимит)
- **MinIO** (локальный Docker)

### Этапы 1-2
- **Self-hosted PostgreSQL** или Yandex Managed
- **Yandex Object Storage** (S3-совместимое)

---

- ❌ Проприетарные фичи Supabase
- ❌ Хранение видео в R2/MinIO
