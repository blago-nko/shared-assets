# Политика безопасности

## Поддерживаемые версии

Поддерживается только актуальное состояние ветки `main` всех репозиториев организации.

## Сообщение об уязвимости

- Предпочтительно: GitHub → Security → Report a vulnerability (приватный отчёт).
- Не создавайте публичные Issue и PR с описанием уязвимостей.

## Регламент ответа

- Подтверждение получения — до 72 часов.
- Триаж и план исправления — до 7 дней.
- Публикация — после выпуска исправления (координированное раскрытие).

## Область действия

Политика распространяется на репозитории организации, включая manifests и shared-assets, а также на инфраструктуру деплоя сайтов экосистемы.
